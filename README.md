# BMS IDPA

This repository contains the code for our IDPA (interdisziplinäre Projektarbeit), an interdisciplinary research paper required for the Swiss vocational baccalaureate (Berufsmaturität). The paper combines computer science and mathematics and is written in German.
The team is composed of Levin, Tobias and Lorin, apprentices in application development.

For further information about the project, see [about.md](docs/about.md).
